# 高匹配候选结果可见性设计

## 目标

“候选结果”只显示 DeepSeek 检索匹配分 `searchFit >= 70` 的候选人。低匹配候选仍保留在任务快照、分析和去重记录中，但不出现在结果列表，也不被删除。

## 数据流

扩展照常读取有界搜索结果，DeepSeek完成 searchFit 分析后写入 `gulu_search_fits`。任务结果接口必须同时匹配岗位、任务、候选人与对应 search fit，并在服务端应用 70 分阈值。前端继续使用原结果接口，因此无法意外展示低分候选。

## 边界

- 过滤是显示规则，不是招聘淘汰或数据删除。
- AI不能单独删除候选人，人工审计所需记录继续保留。
- 任务独立：候选人在其他任务中的高分不能使其出现在当前任务结果中。
- 旧式非战役结果接口保持兼容；本次修改针对带 `runId` 的谷露任务结果。

## 验收

- 同一任务中 69 分候选不返回，70 分候选返回。
- 返回项带有 `searchFit`，便于页面说明高匹配依据。
- 低分候选仍存在于候选、快照和 search fit 数据表中。
- 完整测试、类型检查、构建和 lint 通过。
