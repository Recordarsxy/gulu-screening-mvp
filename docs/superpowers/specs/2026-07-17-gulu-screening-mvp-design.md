# 谷露简历筛选 MVP 设计

## 目标与交付边界

本次交付一个仅在 Windows 工作电脑本机运行的简历筛选网站。它完成岗位资料导入、岗位包生成与审批、模拟候选人筛选、人工复核、导出和数据删除。日常使用不依赖 Codex。

谷露接入保持严格只读：本次可创建本机配对接口、任务状态机和 Chrome 插件安全骨架，但在获得谷露实际域名、脱敏截图或 HTML 快照并完成适配器测试前，不在真实谷露页面执行自动化。不实现收藏、标签、联系、消息、简历下载或任何资料写入。

## 方案选择

采用 Node.js 24 + TypeScript 的本机单机应用，前端使用 React，后端使用小型 HTTP API，数据库使用 Node 内置 SQLite 能力。该方案比 Next.js 更轻、比纯静态页面更适合文件解析、数据持久化和断点恢复，并避免 Windows 上的原生 SQLite 编译依赖。

服务只监听 `127.0.0.1`。用户通过双击 `启动谷露筛选MVP.cmd` 启动，系统将自动打开浏览器。

## 功能模块

1. **岗位管理**：创建稳定岗位 ID，接收粘贴文本、DOCX 和 PDF，记录导入时间、文件哈希和本机副本。
2. **岗位包**：生成人读版《岗位筛选说明》docx 和符合 Schema 的 `job-pack.json`。规则初始为 `draft`，修改必须创建新版本，仅批准版本可以启动筛选。
3. **模拟筛选**：导入或使用内置脱敏候选人，模拟公司轮和职位轮，按稳定 ID 或详情链接去重。先用确定性规则，再对语义不确定内容调用 DeepSeek。
4. **人工复核**：保留机器原判断、原因代码和 1–4 条证据，人工可设置审核状态和备注，不覆盖机器记录。
5. **任务运行**：批次默认 50 人，支持暂停、断点、恢复、去重、缓存和运行摘要。网络错误不引发不受控重试。
6. **导出和删除**：生成包含“全部、推荐、复核、排除、运行摘要”的 Excel 和 UTF-8 CSV。支持导出后按岗位一键删除所有本机业务数据与文件。
7. **设置与诊断**：配置 DeepSeek API 地址和模型，检查 API Key 是否存在但不回显，执行不含真实数据的连接测试，显示耗时、Token 和错误分类。

## DeepSeek 集成

使用 DeepSeek 的 OpenAI 兼容 Chat Completions API，默认 `baseURL` 为 `https://api.deepseek.com`。模型名称不写入业务逻辑；设置页默认为当前官方推荐的 `deepseek-v4-flash`，用户可改为公司账号可用模型。

结构化输出设置 `response_format: {"type":"json_object"}`，提示中明确包含 JSON 结构和示例，响应还必须经本地 Schema 验证。空响应、截断或 Schema 不符时不盲目重试，记录可诊断错误并将相关候选人放入“复核”。

API Key 仅从 `DEEPSEEK_API_KEY` 环境变量或本机安全凭据读取，不写入源码、SQLite、日志或导出文件。

## 数据与安全

SQLite 保存 `jobs`、`job_rule_versions`、`search_tasks`、`runs`、`candidates`、`assessments`、`human_reviews` 和 `audit_events`。历史运行始终绑定当时的规则版本。

云端请求前执行白名单投影与黑名单脱敏。可发送字段仅限必要公司、职位、任职时间、必要经历和批准规则。姓名、手机、邮箱、微信、身份证、住址、照片、谷露 ID 和详情链接不得进入 AI 请求或日志。

年龄、性别、婚育等人口属性不参与自动判断。学历、城市和年限仅在客户明确提出且用户批准时可作为硬条件。信息缺失只能导向“复核”，不能导向“排除”。

## 数据流

1. 本地解析客户需求和 JD，保存原文哈希。
2. 脱敏后调用 DeepSeek 生成岗位包，或在无 API 时用本地可编辑模板完成演示。
3. 用户修改并批准规则版本。
4. 运行器合并双轮候选人并去重，依次执行确定性判断、脱敏 DeepSeek 判断和结果缓存。
5. 本地重新关联候选人身份字段，保存机器结果与 Token 使用量。
6. 用户人工复核，筛选并导出。

## 异常处理

- 文件无法解析：保留原文件和哈希，显示可理解错误，不创建伪成功岗位包。
- DeepSeek 不可用：保存当前进度，停止云端步骤；本地规则筛选和历史数据仍可用。
- 规则未批准：API 和界面双重拒绝启动。
- 运行中断：每完成一名候选人后持久化断点，恢复时跳过已完成去重键。
- 谷露异常：验证码、账号警告、登录失效、页面结构变化、意外进入联系页或连续三次读取失败时立即暂停并保存断点。

## 验证策略

自动测试覆盖：DOCX/PDF 解析、岗位包 Schema、规则版本与批准门槛、脱敏和请求白名单、双轮去重、确定性分类、缓存、暂停/恢复、Excel/CSV 字段与编码、删除级联和 Chrome 插件权限。

端到端演示固定为：创建岗位 → 生成岗位包 → 修改批准 → 双轮模拟筛选 → 查看去重后的推荐/复核/排除 → 填写人工备注 → 导出 Excel/CSV → 验证文件 → 按岗位删除。

## 完成定义

交付需同时包含可运行网站、双击启动脚本、演示数据、自动测试、用户说明和谷露只读接入的后续资料清单。不得将“已登录浏览器”等同于“已验证的安全适配器”。
