# Gulu v1.2 Job Evolution and Round Progress Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build versioned job-change integration, natural-language search-plan import, and an immediately continuing two-round Gulu task with explicit per-round progress.

**Architecture:** SQLite migration v4 adds job-change history, search-plan versions, immutable task plan snapshots, and per-round status/count fields. Server services own versioning and DeepSeek transformations; the Chrome extension reports semantic round events and schedules immediate continuation; React renders job changes, imported plan tags, and two independent round progress rows.

**Tech Stack:** TypeScript 5.9, Node.js 24 `node:sqlite`, Express 5, React 19, Zod 3, Vitest 3, Chrome Manifest V3, DeepSeek chat completions.

## Global Constraints

- All AI behavior uses DeepSeek only.
- Running tasks keep the rule version and search-plan snapshot captured at task creation.
- Company round always precedes role round and role round starts automatically after company completion.
- Editing a confirmed search plan creates a draft and resets dry-run/pilot rollout flags.
- Never collect or transmit phone, email, Wechat, address, photo, notes, resume attachments, or cookies.
- Never add Gulu write actions, CAPTCHA bypass, arbitrary selectors, or arbitrary script execution.
- v1.1.0 remains unchanged as the rollback release; the new release version is v1.2.0.
