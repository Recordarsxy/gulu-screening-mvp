# 谷露简历筛选 MVP

这是只在 Windows 本机运行的辅助筛选网站。它支持导入客户要求和 JD、生成岗位包、人工批准规则、使用模拟候选人执行双轮筛选、暂停/恢复、人工复核，并导出 Excel/CSV。

当前版本不会操作真实谷露。Chrome 已登录不代表页面适配器已经安全验证；`extension/` 默认禁用。

## 启动

1. 安装 Node.js 24 或更高版本。
2. 双击 `启动谷露筛选MVP.cmd`。
3. 网站会自动打开 `http://127.0.0.1:4318`。

服务只监听 `127.0.0.1`，不会向局域网或公网开放。

## DeepSeek

网站的全部 AI 行为只使用 DeepSeek：岗位/JD 理解、搜索计划生成、候选经历分析。网站生产运行不调用、也不依赖 Codex 或其他模型服务。

- API 地址：`https://api.deepseek.com`
- 默认模型：`deepseek-v4-flash`
- Key：环境变量 `DEEPSEEK_API_KEY`

首次配置时，在项目目录复制 `.env.example` 为 `.env`，只在本机填写：

```text
DEEPSEEK_API_KEY=你的_Key
```

重新双击启动程序后生效。Key 不会写入源码、数据库、日志或导出文件；`.env` 已被 Git 忽略。设置页的连接测试只发送固定无敏感文本。没有 Key 时，只使用本机明确规则和基础模板，不执行任何 AI 行为；人工复核和导出仍可使用。

## 使用流程

1. 在“岗位管理”粘贴客户要求/JD，或上传 DOCX、PDF、TXT。
2. 在“规则审核”逐行编辑硬条件、加分项、目标公司、职位、正面证据和明确反证。
3. 保存修改会产生新的草稿版本；点击“批准规则”。
4. 在“运行中心”分批执行 10 名模拟候选人的双轮筛选，可暂停和恢复。确定性规则无法判断时，若已配置 DeepSeek，则仅发送脱敏经历进行分析；失败自动转人工复核。
5. 在“候选结果”查看推荐、复核、排除、原因代码和证据，填写人工状态与备注。
6. 导出 Excel 或 CSV，必要时下载岗位说明 DOCX 和 `job-pack.json`。

缺失信息只进入“复核”，不会直接“排除”。年龄、性别、婚育不参与自动判断，最终决定始终由人工审核。

## 数据、备份与恢复

- 数据库：`data/gulu-screening.sqlite`
- 上传副本：`data/uploads/`
- 导出：由浏览器保存到用户选择的位置

备份时先关闭网站，然后复制整个 `data/` 目录。恢复时关闭网站，用备份目录替换 `data/` 后重新启动。删除岗位时，网站会级联删除该岗位的规则、候选人、评估、复核和上传副本；操作前应先导出。

## GitHub 版本更新规范

每个版本遵守以下顺序：

1. 从默认分支创建 `codex/<版本说明>` 分支；
2. 完成开发并运行全部验证；
3. 只提交本版本相关文件；
4. 推送分支并创建草稿 PR；
5. PR 描述写明变更、影响和验证结果；
6. 审核合并后创建语义化版本标签，例如 `v1.0.0`。

首次发布前需要：GitHub CLI 有效登录、项目配置 `origin` 远程仓库。当前功能分支为 `feat/gulu-screening-mvp`。

## 真实谷露接入前还需要

- 实际域名；
- 脱敏搜索结果页和候选详情页截图或 HTML 快照；
- 公司允许读取的字段说明；
- Chrome 扩展安装策略。

快照测试通过前不得启用真实页面内容脚本，不得收藏、打标签、发消息、读取联系方式或修改任何人才数据。
