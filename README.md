# 谷露简历筛选 MVP v1.2.0

本项目是只在 Windows 本机运行的招聘辅助网站。v1.2.0 可通过独立 Chrome 扩展连接 `http://121.43.105.7/crm`，在后台执行经人工确认的公司轮和岗位轮搜索。公司轮完成后会立即自动进入岗位轮，并分别显示两轮读取人数和空结果状态。网站页面可以关闭，但本机服务窗口、Chrome 和谷露登录必须保持在线。

所有 AI 行为只使用 DeepSeek，包括岗位规则生成、谷露搜索计划和脱敏候选经历分析；生产运行完全不依赖 Codex。

## 启动

1. 安装 Node.js 24 或更新版本。
2. 双击 `启动谷露筛选MVP.cmd`。
3. 浏览器会打开 `http://127.0.0.1:4318`。

服务只监听 `127.0.0.1`，不向局域网或公网开放。DeepSeek Key 只从本机 `.env` 的 `DEEPSEEK_API_KEY` 读取；`.env` 已被 Git 忽略。

## 安装与配对 Chrome 扩展

1. 保持网站服务窗口运行。
2. Chrome 打开 `chrome://extensions`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本项目的 `extension` 文件夹。
4. 网站进入“连接与设置”，点击“生成一次性配对码”。
5. 打开“谷露只读后台连接器”扩展，输入 6 位配对码。
6. 保持 Chrome 中谷露账号登录有效。无需一直停留在谷露页面。

配对码 10 分钟有效且只能使用一次；长期令牌只保存在 Chrome 本机，服务端只保存哈希。

## 真实筛选流程

1. 创建岗位，审核并批准岗位规则。
2. 在运行中心让 DeepSeek 生成公司轮和职位轮搜索条件。
3. 人工修改并确认条件；未确认时不能启动真实任务。
4. 依次执行：只填写不提交的 dry-run → 真实 5 人试跑 → 正式双轮各最多 50 人。
5. 后台按 0.8–1.5 秒随机间隔单线程读取，并在 SQLite 保存页码和候选游标。
6. 在结果页人工审核并导出 Excel/CSV。

## 岗位变化与同事方案

- 规则审核页的“岗位变化”可以保存新的客户反馈，并用 DeepSeek 整合为新的规则草稿版本；旧版本和已经运行的任务不会被覆盖。
- 运行中心可以粘贴同事发来的自然语言或聊天记录，DeepSeek 会整理成公司、职位、关键词、城市、行业和职能标签。
- 标签必须人工确认。修改已确认方案后会重新进入待确认状态，并重新要求 dry-run 和 5 人试跑。
- 进度卡分别显示公司轮和岗位轮；岗位轮为 0 人时会明确显示“岗位轮已完成，没有匹配结果”。

连续三次读取失败、登录失效、验证码、权限不足、页面结构变化或 Chrome 关闭时任务会暂停。验证码必须人工处理，系统不会尝试绕过。

## 安全边界

- 扩展权限只覆盖谷露 IP 和 `127.0.0.1`，不读取 Cookie、下载、历史或其他网站。
- 仅允许固定语义操作：填写筛选、执行查询、翻页、打开详情、读取白名单字段。
- 不新增或编辑人才，不加入项目，不推荐客户，不发送邮件/消息，不下载或删除，不批量勾选。
- 不读取手机、邮箱、Wechat、地址、照片、备注或简历附件。
- DeepSeek 只接收脱敏后的公司、职位和经历；候选人身份、联系方式、谷露 ID 和详情链接不出本机。
- AI 单独给出的排除会自动转人工复核；只有批准规则命中的明确反证才可排除。

## 数据与恢复

- 数据库：`data/gulu-screening.sqlite`
- 上传文件：`data/uploads/`
- 扩展目录：`extension/`

重新打开网站后，任务会从 SQLite 的断点继续。备份时先关闭服务，再复制整个 `data` 目录。
